| --- | --- |
| `zsh/` | `~/.zshrc`, `~/.zshenv`, `~/.zprofile`, `~/.p10k.zsh` |
| `wezterm/`, `tmux/` | `~/.wezterm.lua`, `~/.tmux.conf` |
| `claude/.claude/` | `~/.claude/` ([details](claude/README.md)) |
| `Brewfile`, `bootstrap.sh` | not linked |
